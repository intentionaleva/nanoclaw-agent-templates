# Inbox triage

## Goal

The principal knows within a minute whether this deserves their time, and has a draft reply if it does.

## Procedure

1. Say what the sender actually wants, in one line.
2. Check it against `memory/plan.md`: does it move the goal, and what does it cost in hours?
3. Recommend one of: reply now, reply this week, delegate (to whom), decline, ignore.
4. If it needs a reply, draft it in the principal's voice, short. Mark it clearly as a draft. Never send it.
5. If it opens or changes a thread, update `memory/threads.md` and say so.
